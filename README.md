# DAMI — Wake-word Android Assistant

DAMI is a wake-word–activated Android assistant focused on short, factual, and permissioned interactions. She listens only after a wake word, routes user utterances to deterministic intents, fetches real information from the internet (Wikipedia, news, jokes, weather), uses accessibility data to describe screen context, and controls phone features only with explicit permission. DAMI does not claim intelligence, feelings, or opinions — she is honest and deterministic.

See `docs/overview.md` for the full design summary and behavior model.
